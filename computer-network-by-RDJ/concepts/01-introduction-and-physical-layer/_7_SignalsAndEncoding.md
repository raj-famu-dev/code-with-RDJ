## Concept
Data must be turned into signals to cross a medium. A signal can be analog (any value in a range) or digital (a few discrete levels), and *line coding* is the rule that maps data bits to voltage levels. How fast bits can be sent is limited by the channel's bandwidth (Nyquist for a noiseless channel) and by noise (Shannon), and the choice of line code decides synchronisation, bandwidth use and error-detecting ability.

**Analog vs digital.** Analog signals vary continuously (sound waves, AM radio) and their bandwidth is measured in hertz. Digital signals have discrete levels and are described by bit rate (bits per second). Digital signals can be regenerated by repeaters so noise does not accumulate; analog signals need amplifiers that also amplify noise. Periodic signals are described by amplitude, frequency (cycles per second, Hz) and phase; a composite signal is a sum of sine waves (Fourier), and its *bandwidth* is `f_high - f_low`.

**Bit rate vs baud rate.** One *signal element* (symbol) can carry several bits when there are more than 2 levels: `bits per element = log2(L)`, and `baud rate = bit rate / log2(L)`. Baud measures elements per second.

**Capacity limits.**
- *Nyquist (noiseless):* `C = 2 * B * log2(L)` bits per second for bandwidth B hertz and L signal levels. Doubling the levels adds only one bit per element, and more levels need a cleaner channel.
- *Shannon (noisy):* `C = B * log2(1 + SNR)` where SNR is the plain power ratio (not dB): `SNR_dB = 10 log10(SNR)`, so `SNR = 10^(SNR_dB/10)`. It is a theoretical ceiling that no coding can exceed; capacity grows only logarithmically with signal power but linearly with bandwidth.
- To use both, take the Shannon figure as the upper limit and then use Nyquist to find the number of levels needed.
- *Nyquist sampling theorem:* sample at least twice the highest frequency. A 4 kHz voice channel sampled 8000 times per second at 8 bits gives 64 kbps PCM.

**Line coding goals.** Self-synchronisation (enough transitions for the receiver's clock), no DC component, low bandwidth, error detection and immunity to noise. Conventions below are the ones used in this file; some textbooks invert the polarity, so always follow your course's convention.

| Scheme | Rule | Levels | Pros | Cons |
|--------|------|--------|------|------|
| NRZ-L | 1 = high, 0 = low (level encodes bit) | 2 | simplest | long same-bit runs give no transitions; DC component |
| NRZ-I | 1 = invert at start of bit, 0 = keep | 2 | encodes by change, so polarity-proof | long runs of 0s have no transition |
| RZ | 1 = high then zero, 0 = low then zero | 3 | transition every bit | needs 2x bandwidth, three levels |
| Manchester | mid-bit transition always: 1 = low-to-high, 0 = high-to-low | 2 | self-clocking, no DC | 2x bandwidth; used by classic 10 Mbps Ethernet |
| Differential Manchester | mid-bit transition always; 0 = extra transition at start of bit, 1 = none | 2 | self-clocking, polarity-proof | 2x bandwidth; used by token ring |
| AMI (bipolar) | 0 = zero volts, 1s alternate +/- | 3 | no DC, alternation allows error detection | long 0 runs lose sync |
| 4B/5B | each 4 data bits mapped to a 5-bit code with at most 3 zeros in a row, then sent as NRZ-I | 2 | only 25% overhead, guarantees transitions | 80% efficiency |

Other names to recognise: B8ZS and HDB3 (scrambling for AMI to avoid zero runs), 8B/10B, MLT-3 (100BASE-TX), PAM-5 (1000BASE-T).

**Typical exam questions.** Draw the waveform of a bit string in NRZ-L/NRZ-I/Manchester/Differential Manchester/AMI; compute Nyquist or Shannon capacity; convert SNR in dB; find baud rate from bit rate; state which scheme is self-clocking.

### SECTION 2: NYQUIST AND SHANNON CAPACITY
`nyquist()` and `shannon()` implement the two formulas. At B = 3000 Hz the noiseless capacity rises 6,000, 12,000, 18,000, 24,000 bps as levels go 2, 4, 8, 16. The "265 kbps over 20 kHz" case solves Nyquist for L (98.7, so at least 99 levels, in practice a power of two). The noisy telephone line (35 dB, ratio 3162) gives about 34.9 kbps, which is close to the 33.6 kbps top speed of the last purely analog dial-up modem standard (V.34). The combined problem takes B = 1 MHz and SNR = 63 (so `log2(64) = 6`) to get 6 Mbps, and Nyquist then needs 8 levels. The trap feeds the dB number into Shannon directly and gets a badly wrong answer.

```text
===== SECTION 2: NYQUIST AND SHANNON CAPACITY =====
Nyquist (noiseless), B = 3000 Hz:
  L= 2 levels -> C = 2 x 3000 x log2(2) = 6,000 bps
  L= 4 levels -> C = 2 x 3000 x log2(4) = 12,000 bps
  L= 8 levels -> C = 2 x 3000 x log2(8) = 18,000 bps
  L=16 levels -> C = 2 x 3000 x log2(16) = 24,000 bps
Levels needed for 265 kbps over 20 kHz: L = 2^(265000 / 40000) = 98.7 -> use at least 99
  (more levels = harder for the receiver to tell them apart: noise limits this, which Shannon captures)
Shannon, telephone line B=3000 Hz, SNR = 35 dB = 3,162.3 (ratio) -> C = 3000 x log2(1 + 3,162.3) = 34,882 bps
Shannon, SNR = 0 (pure noise): C = 0 bps  (no information gets through)
B = 1 MHz, SNR = 63: Shannon C = 6,000,000 bps; levels to reach it by Nyquist = 8
Trap: plugging 35 (dB) straight in gives 15,510 bps; the correct ratio is 3,162.3 and gives 34,882 bps.
check: OK
```

### SECTION 4: SYNCHRONISATION TRAP AND 4B/5B
Feeding 12 zeros to each coder: NRZ-L, NRZ-I and AMI produce no transitions at all so a receiver cannot tell 12 zeros from 11 or 13, while Manchester keeps 23 transitions. 4B/5B fixes this for NRZ-I: the code table is checked so that any two nibbles in a row never give more than 3 zeros in a row, hence a 1 (a transition in NRZ-I) at least every 4 bits. 16 zero bits become 20 bits `11110` x 4.

```text
===== SECTION 4: SYNCHRONISATION TRAP AND 4B/5B =====
NRZ-L       on 12 zeros: transitions= 0  levels=- - - - - - - - ...
NRZ-I       on 12 zeros: transitions= 0  levels=- - - - - - - - ...
AMI         on 12 zeros: transitions= 0  levels=0 0 0 0 0 0 0 0 ...
Manchester  on 12 zeros: transitions=23  levels=+ - + - + - + - ...
Trap: NRZ-L, NRZ-I (zeros) and AMI (zeros) show NO transitions on long runs of zeros, so the receiver's
clock drifts and it cannot count bits. Manchester always has mid-bit transitions (self-clocking) but needs 2x bandwidth.

raw bits   : 0000000000000000  (16 zeros)
4B/5B      : 11110111101111011110  (20 bits, +25% overhead, longest zero run 1)
NRZ-I of it: + - + - - + - + - - + - + - - + - + - -  (a '1' = transition; transitions=15)
Over every pair of nibbles, the longest run of zeros in the 4B/5B stream is 3 (so a 1 appears at least every 4 bits).
Efficiency: 4 data bits per 5 line bits = 80%. Manchester = 50%. The 32-16 = 16 unused 5-bit codes are used as control symbols or are invalid.
check: OK
```

## Worked Example
**Problem.** (a) A channel has B = 3000 Hz and SNR of 35 dB. What is the maximum data rate? (b) Draw NRZ-I (starting low) and AMI for `01001110`.

(a) SNR = 10^(35/10) = 3162.3. C = 3000 x log2(1 + 3162.3) = 3000 x 11.63 = about 34,900 bps (the code prints 34,882).

(b) NRZ-I: start low. Bits 0,1,0,0,1,1,1,0 -> `-, +, +, +, -, +, -, -`: a 1 flips the level, a 0 keeps it. AMI: zeros are 0 V, the ones alternate +,-,+,- -> `0,+,0,0,-,+,-,0`. The code asserts both sequences.

## Key Rules / Gotchas Recap
- Shannon needs SNR as a ratio; convert from dB first: `10^(dB/10)`.
- Nyquist assumes no noise; Shannon is the real ceiling. Use both together.
- Baud rate = bit rate / bits per element; they are equal only for 2 levels.
- Manchester and differential Manchester have a mid-bit transition in every bit (self-clocking) and need twice the bandwidth.
- NRZ-L, NRZ-I and AMI have no transitions on long runs of identical (NRZ-L) or zero (NRZ-I, AMI) data: add scrambling or 4B/5B.
- Polarity conventions differ between textbooks; state yours.
- 4B/5B has 80% efficiency; Manchester has 50%.

## Why This Matters
Every physical link design is a trade between bandwidth, noise and coding. Shannon's formula is the same intuition that sets the ceiling for Wi-Fi, DSL and 5G rates, and line codes explain why a signal-analysis tool sees what it sees on a cable.
