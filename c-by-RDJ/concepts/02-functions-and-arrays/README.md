# Functions and Arrays

Function declarations, parameter passing, arrays and null-terminated strings

Each topic has a standalone C17 source file and a matching Markdown walkthrough. Compile one file at a time with:

    cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -g _1_Example.c -o demo
    ./demo
