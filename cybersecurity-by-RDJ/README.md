## 📌 About

This is the security track of [`code-with-RDJ`](../README.md): network security learned properly — on systems I own, in legal training labs, and on CTF platforms.

The rule comes from the repository root and is enforced in code by the tools themselves (the [`project-02-network-scanner`](../python-by-RDJ/projects/project-02-network-scanner) refuses public hosts):

> Security work is done **only** on systems I own, in legal training labs, and on CTF platforms. No real-world targets, no stolen data, and no malware outside a lab.

- **What will live here:** CTF write-ups with named platforms and dates, legal lab exercises, and the prompt-injection testing tool (built only against applications I own).
- **What will never live here:** anything that targets a system I don't own, or any claim of a ranking without a public profile link, a platform name, a number and a date.
